# AIRA - Artificial Intelligence Research Assistant

Created by Joss Collen

## Features
- 🗣️ Female voice (pyttsx3)
- 🖱️ Desktop control (PyAutoGUI)
- 🌐 Browser automation
- 💬 Chat interface
- 🎨 Futuristic UI

## How to Run
1. Double-click `START.bat`
2. Open http://localhost:5000
3. Start chatting!

## Tech Stack
- Python + Flask
- pyttsx3 (voice)
- PyAutoGUI (desktop control)
- HTML/CSS/JS (UI)
